## 🚀 About the Repo

Welcome to my **React Refresher** repository! This is my personal codebase and sandbox where I deconstruct, practice, and master every fundamental and advanced concept in modern React. Whether it is rendering mechanics, custom hooks, or state management, this repo serves as my ultimate cheatsheet and proof-of-work.

---

## 📚 What's Covered

Here is a breakdown of the concepts and modules included in this refresher:

*   **🧱 Fundamentals:** Components, JSX, Props, and Conditional Rendering.
*   **⚡ State & Lifecycle:** `useState`, `useEffect`, and understanding the React render cycle.
*   **🎣 Hooks Deep-Dive:** `useRef`, `useMemo`, `useCallback`, `useReducer`, and custom hooks.
*   **🔄 State Management:** Context API, lifting state up, and modern global patterns.
*   **🧭 Routing & Side Effects:** Client-side routing, data fetching, and error boundaries.
*   **🏎️ Performance Optimization:** Memoization, lazy loading, and avoiding unnecessary re-renders.
